# Rock Paper Scissors ✊✋✌️

A simple browser-based Rock Paper Scissors game. First player to reach 5 points wins. 

Built with vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies.

### **Demo**
https://huma542.github.io/Rock-paper-scissors/

### **Features**
- Play against computer with random choice logic
- Score tracking for player and computer
- First to 5 points wins the match
- "Play Again" button to reset the game
- Disabled buttons when game ends
- Clean, responsive UI

### **How to Run**
1. Clone or download this repo
2. Make sure `index.html` and `script.js` are in the same folder
3. Double-click `index.html` or drag it into your browser

No build step or npm install needed.
